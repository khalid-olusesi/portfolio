Getting Started

Prerequisites

A modern web browser and Git.

Installation

Clone the repository:

git clone https://github.com/khalid-olusesi/portfolio.git

Navigate into the project directory:

cd portfolio

Open index.html in your browser.

Alternatively, use the Live Server extension in VS Code to run the website locally.

Deployment

The portfolio is deployed on Vercel.

Live URL: https://portfolio-sepia-one-b6mxzl55vn.vercel.app/
